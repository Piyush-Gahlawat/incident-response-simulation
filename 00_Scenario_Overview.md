# Incident Simulation: Project NovaCorp Ransomware Attack

**Purpose:** This repository contains a comprehensive Incident Response (IR) and Business Continuity Plan (BCP) simulation. It demonstrates the operational steps, recovery metrics (RTO/RPO), and post-incident analysis required to manage a severe enterprise cyber-attack.

## The Scenario
**Company:** NovaCorp (Fictional FinTech managing 50,000 active users).
**Date of Incident:** Thursday, 14:00 UTC.
**Attack Vector:** A phishing email bypassed the spam filter. An employee downloaded a malicious attachment, allowing threat actors to deploy ransomware across the primary data center. 

**Current Impact (00:00 Hours):**
- Core banking web portal is offline.
- Customer database is encrypted.
- Backups are intact but the restoration process has never been tested.

**The Goal:**
Execute the Incident Response Playbook, calculate the financial and operational impact, restore services within the agreed RTO (Recovery Time Objective), and document the Root Cause Analysis.
